# Greater Bay Area Industrial Transformation Dashboard

![Preview](https://yunxindeng.github.io/) 
![屏幕截图 2025-06-12 170509](https://github.com/user-attachments/assets/8e957c6d-0294-4594-afc9-a569f476883f)


An interactive data visualization platform analyzing industrial transformation in China's Guangdong-Hong Kong-Macao Greater Bay Area (GBA), covering four key dimensions:

## Key Modules

### 🌐 International Trade
- Import/export trends (2015-2023)
- Top trading partners analysis
- Key commodity flows visualization
- Customs special supervision zones performance

### 🧑‍🤝‍🧑 Demographic Shifts
- Population migration patterns
- Talent inflow/outflow heatmaps
- Age structure evolution
- Higher education talent pool

### 💰 Economic Transition
- GDP growth by city cluster
- Industrial structure Sankey diagrams
- R&D investment trends
- Patent applications mapping

### 🏗️ Urban Regeneration
- Major renewal project locations
- Land use transformation
- Brownfield redevelopment cases
- Infrastructure investment analysis

## Data Sources
- Guangdong Statistical Yearbook
- Hong Kong Census and Statistics Dept
- Macao DSEC
- China Customs Database
- GBA Policy Documents

## Technical Stack
    A[D3.js] --> B{Visualizations}
    C[Chart.js] --> B
    D[Mapbox GL] --> E[Geospatial Analysis]
    F[Python Pandas] --> G[Data Processing]
    H[Flask] --> I[API Endpoints]
